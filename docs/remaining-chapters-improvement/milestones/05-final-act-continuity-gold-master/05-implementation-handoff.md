# 05 - Implementation Handoff

## Handoff state

This package is planning-only and approval-ready. Begin only after Milestones 01-04 are accepted, the user approves this package, and a Git checkpoint is created or authorized.

## Implementer

Luna, XHIGH effort, one `/goal`, one worktree. Sol performs independent review after Luna records evidence. Do not run overlapping implementation in these files.

## Read order

1. Root `AGENTS.md` and `docs/project-status.md`.
2. Top-level remaining-chapters program, all three chapter visions, continuity map, and roadmap.
3. Accepted evidence from Milestones 01-04.
4. This package's README, audit, spec, plan, and matrix.

## Concrete outcome

Deliver one continuous, replayable, failure-tolerant final act whose approved choices change presentation rather than challenge, whose Credits page resolves the prequel as narrative, and whose full-run evidence is sufficient for the user's gold-master playtest.

## Definition of done

- All four choice layers reconstruct and appear at their approved seams.
- No consequence changes difficulty, access, or completion.
- Credits has branch-specific release imagery, authored four-part run copy, replay, and reset confirmation.
- SIGNAL silence and Chapter 3/4 audio balance/failure behavior are verified.
- All required viewports, inputs, motion preferences, failures, interruption, replay, and persistence cases are evidenced.
- Lint/build/diff pass; console/hydration/scope review is clean or carries named baselines.
- README checklist/verdict and evidence links are updated.
- No protected contract, renderer design, parked scope, or Git state changes without approval.

## Evidence format

For every matrix row record result, environment, observed behavior, and evidence path. Label each failure as inherited baseline, new regression, or approved deviation. A source inference is not browser/playtest proof.

## Stop and escalate

Stop before changing state shape/values, canon, accepted mechanics, renderer mapping, direct-route policy, outside-world content, adding audio assets, creating shared renderer state, touching unrelated chapters/shell, or performing Git actions.
