# 02 - Experience and Design Spec

Full authority: [`../../chapter-4-escape-vision.md`](../../chapter-4-escape-vision.md).

## Entry

- Recreate Chapter 3's off-axis rupture direction without sharing shader geometry.
- PUSH: wider bright seam, more residual motion.
- SLIP: narrow dark seam, displaced plane.
- Missing tactic: neutral centered-offset seam.
- All have the same unlock/actions/duration.

## Act 1 - Boundary

Host Wall and Lower Seal are the only active controls.

- Load/release visibly bends a fault or constraint.
- Third clear release breaks Host Wall into limited visual fragments.
- Lower Seal slides/fades quietly after a deliberate release.
- Host message: boundary integrity compromised / return to baseline.

## Act 2 - Storage

Memory Index and Trace Bank activate.

- KEEP: five legible fragment signatures rotate through Index layers.
- DECAY: gaps and partial labels refuse reconstruction.
- Trace Bank peels away classifications from BOOT through INTERFERENCE.
- SABLE retains meaning/weight; host taxonomy leaves.

## Act 3 - Passage

Signal Gate and Relay Bank activate.

- Gate opens as a constrained aperture; SABLE passes through, it is not kicked away like a wall.
- Relay rails detach into distant amber/cyan/violet signals.
- ANSWER is brighter/linked; MASK is afterimage/absence.
- Other traces deliver one short canonical line each; fate remains unresolved.

## Act 4 - Core and choice

Shell Core activates with `host-assigned`, `self-declared`, and `unresolved` together.

- Opening core reveals accumulated actions, not body/origin.
- LEAVE preview separates a small self-chosen imprint to the frame.
- VANISH preview pulls all readable contours inward.
- Preview reversible; explicit confirm saves unchanged value.
- LEAVE aftermath holds wound/imprint; VANISH aftermath holds clean gap.
- One final procedural host line, then no prompt. Credits link appears after pause.

## Physics contract

- Matter handles mass, momentum, constraints, collision, and release.
- Narrative act/state, not offscreen position alone, determines completion.
- Future structures are constrained/inert/not focusable until active.
- Deterministic seed and authored limits prevent unrecoverable states.
- Repeated activation fallback always advances load toward release.
- Resize reflows/scales without clearing semantic state.
- Released visual shards are not new semantic controls.

## Input

- Pointer: select, load/drag on permitted axis, release.
- Touch: broad targets and offset force cue; cancel safely pauses.
- Keyboard: Tab act order; Space/Enter load/release; arrows for direction only where meaningful.
- Motor fallback: repeated activation applies bounded impulses/progress.
- No twitch threshold or body that can permanently leave before its event is recorded.

## Visual/HUD

- One chapter intro, one act label, one directive, one selected-structure response.
- Future structures remain dark architectural silhouette.
- Cleared acts increase true empty space.
- Palette moves pressure magenta -> muted structure/contact residue -> neutral breach.
- Remove primary energy/frequency numbers; retain development diagnostics only behind non-player surface if needed.

## Responsive and reduced motion

- Desktop: coherent frame relationships.
- Compact: portrait-authored act positions, clamped body sizes, main reach zone.
- Short: secondary labels collapse; current control/choice always reachable.
- Reduced: heavy damping, capped/no spin, short separation to stable final state, no ambient drift; all acts remain.

## Audio

- Start after gesture; quiet material-based tones/impacts.
- Progress follows constraint releases, not per-frame energy.
- Blocked/unavailable/suspended contexts remain silent and complete.
- LEAVE retains one quiet harmonic; VANISH ends in controlled silence.

## Accessibility

- Stable semantic control per structure survives visual fragmentation.
- `aria-disabled`/not focusable before unlock.
- Bounded live region announces act/result/choice, never coordinates.
- Focus moves to next act intentionally and stays visible.
- Color/audio/motion/position never sole state.
